## 1. Executive Summary & Objective

This audit investigates the empirical provenance, task formulation, and mathematical reproducibility of the reported **99.94% classifier accuracy** (1,724 correct out of 1,725) and reconciles it against the historical **86.92%** EfficientNet-B0 accuracy claim.

**Key Findings:**
1. **Distinct Task Formulations:** The 99.94% and 86.92% metrics evaluate **two fundamentally different computer vision tasks** executed by different model checkpoints:
   - **99.94%:** **15-Class Visual Category Recognition** (multi-class product SKU identification for automatic routing: "Is this a bottle, cable, capsule, ...?").
   - **86.92%:** **Binary Defect Classification** (supervised anomaly classification: "Is this specific specimen normal or defective?").
2. **Provenance & Reproducibility:** The 99.94% result is **100% reproducible** and supported by raw per-image predictions in `release/category_recognition/category_test_predictions.csv` generated by `DefectVisionAI/models/category_classifier/category_classifier.pth`.
3. **Quarantine & Data Separation:** Evaluated on the official 1,725 MVTec AD test split with **zero overlap** (0 images) with the 2,903 training and 726 validation samples.
4. **Resolution:** The headline claim must explicitly state **"15-Class Category Recognition Accuracy: 99.94%"** to prevent conflation with binary defect detection.

## 2. Forensic Audit of the 99.94% Category Recognition Result

### 2.1 Task Formulation & Model Specification
- **Task:** Closed-set multi-class category recognition with open-set OOD rejection.
- **Model Checkpoint:** `DefectVisionAI/models/category_classifier/category_classifier.pth` (17,656,565 bytes, SHA-256 verified).
- **Architecture:** Timm `efficientnet_b0` backbone with a custom linear head ($1280 \to 15$ classes).
- **Number of Output Classes:** 15 (`bottle`, `cable`, `capsule`, `carpet`, `grid`, `hazelnut`, `leather`, `metal_nut`, `pill`, `screw`, `tile`, `toothbrush`, `transistor`, `wood`, `zipper`).
- **Temperature Scaling Parameter:** $T = 1.3696$ (calibrated via NLL minimization on holdout validation data).

### 2.2 Dataset Partition & Overlap Verification
- **Training Set Manifest:** `release/dataset_manifests/category_classifier_train_split.csv` ($N = 2,903$ nominal images).
- **Validation Set Manifest:** `release/dataset_manifests/category_classifier_val_split.csv` ($N = 726$ nominal images).
- **Evaluation Test Set:** `release/category_recognition/category_test_predictions.csv` ($N = 1,725$ test images).
- **Overlap Audit:**
  $$\text{Train} \cap \text{Val} = \mathbf{0}, \quad \text{Train} \cap \text{Test} = \mathbf{0}, \quad \text{Val} \cap \text{Test} = \mathbf{0}$$
  All 1,725 test images (467 normal and 1,258 defective specimens across all 73 physical defect types) were held out from model training and hyperparameter selection.

## 4. Reconciling 99.94% with Historical 86.92%

A comparison of the evaluation protocols resolves the apparent discrepancy:

| Dimension | 15-Class Category Recognition (99.94%) | Supervised Binary Defect Classifier (86.92%) |
|---|---|---|
| **Target Task** | Multi-class product SKU identification | Binary anomaly detection (Normal vs. Defective) |
| **Output Space** | 15 discrete product classes | 2 classes (Nominal: 0, Defective: 1) |
| **Model Weights** | `models/category_classifier/category_classifier.pth` | `models/efficientnet_baseline_v3/best_model.pt` |
| **Evaluation Set** | 1,725 official MVTec AD test images | 856 development-exposed MVTec AD specimens |
| **Performance** | $1,724 / 1,725$ correct ($99.94\%$) | $764 / 856$ correct ($86.92\%$) |
| **Failure Mode** | 1 texture misclassified with high entropy | 111 defects escaped ($82.24\%$ recall, $17.76\%$ FNR) |
| **Scientific Role** | Front-end automated SKU router | Historical baseline demonstrating need for PatchCore |
