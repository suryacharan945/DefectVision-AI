## 2. Technical Analysis: Why Few-Shot Adaptation Resolves the False Alarm Crisis

### The Failure of Zero-Shot Transfer
Under the uncalibrated MVTec baseline, nominal bottle specimens exhibit peak PatchCore distances $d_i \in [2.4, 4.2]$, while the frozen MVTec decision threshold is $\tau = 0.8333$. Even with foreground masking, minor variations in glass refraction, conveyor backlight spectral temperature, and camera focal distance cause nominal patches to lie outside the MVTec distribution, resulting in a **100% false positive rate**.

### The Mechanism of Few-Shot Adaptation
1. **Feature Extraction with Frozen ResNet-18:**
   No backbone fine-tuning or weight modification is performed. Mid-level features ($384$-D) remain fixed, preserving robust general feature representation while avoiding catastrophic forgetting.
2. **Strict Calibration Isolation:**
   Uploaded normal reference samples are partitioned into:
   - **Training subset:** Used exclusively to construct the raw memory bank and compute the coreset subsampling ($10\%$).
   - **Held-out calibration subset:** Strictly quarantined from memory-bank generation. Scored against the temporary model to compute empirical score distribution percentiles ($p_{50}, p_{90}, p_{99}$).
   - **Provisional threshold formula:**
     $$\tau_{\text{provisional}} = \max(S_{\text{cal}}) + \max(0.08, 0.5 \cdot \sigma_{\text{cal}})$$
3. **Coreset Reduction & FAISS Indexing:**
   Minimax greedy reduction compresses the memory bank by $90\%$, yielding an index size of $392$ vectors ($602$ KB). Distance evaluation against `IndexFlatL2` executes in under $15\text{ ms}$ on CPU.

## 4. Complete Profile Lifecycle Management

DefectVision AI provides full REST API and frontend lifecycle control for adapted profiles:

1. **Intake & Screen:** Optical quality verification via `UniversalImageIntakeService`.
2. **Build & Register:** `/api/production-profiles/adapt` builds memory bank and FAISS index.
3. **Activate / Deactivate:** `/api/production-profiles/{id}/activate|deactivate` toggles live inspection routing.
4. **Archive:** `/api/production-profiles/{id}/archive` unloads model from RAM while preserving disk artifacts.
5. **Evaluate:** `/api/production-profiles/{id}/evaluate` runs batch empirical evaluation on held-out test sets.
6. **Update References:** `/api/production-profiles/{id}/update-references` incorporates new normal samples with automatic minor version bump.
7. **Delete:** `/api/production-profiles/{id}` permanently purges profile directory and model cache.
